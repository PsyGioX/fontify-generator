# Fontify — Web Font Generator

Generate **CSS, HTML and Tailwind** code for web fonts from **Google Fonts** or your own
**TTF / OTF / WOFF / WOFF2** files. Live preview, weight picker, ZIP download.
Everything runs in the browser — uploaded files never leave your device.

Repository: <https://github.com/PsyGioX/fontify-generator>

## Features

- Google Fonts: paste a `fonts.google.com` / `fonts.googleapis.com` link or just a font name
- Choose weights (100–900) and italic; the code and the preview update instantly
- Upload TTF, OTF, WOFF or WOFF2 (up to 10 MB, validated by file signature)
- Editable preview text and size, paragraph and glyph specimens
- CSS, HTML and Tailwind CSS v4 (`@theme`) snippets with one-click copy
- ZIP package: CSS + font file + demo page
- English / Russian UI, light / dark / system theme, fully responsive, accessible

## Development

Requires Node.js 20.19+ (22 recommended).

```bash
npm install
npm run dev        # http://localhost:8080
npm run lint
npm run build      # type-check + production build
npm run audit      # npm audit for known vulnerabilities
```

## Deployment & SEO

Set `VITE_SITE_URL` (for example `https://fonts.example.com`) in your hosting environment so the
canonical URL, Open Graph tags, `sitemap.xml` and `robots.txt` point to your domain. On Vercel the
production domain is detected automatically. `vercel.json` ships a strict Content-Security-Policy
and other security headers.

Brand assets (favicon set, app icons, social preview) are generated by
`python3 scripts/generate-brand-assets.py` (needs Pillow and numpy).

## Security

Dependencies are kept at versions with no known advisories (`npm audit` reports 0 vulnerabilities
as of 2026-10-22). Dependabot and a weekly CI audit keep it that way. Google Fonts input is parsed
with the `URL` API against exact hostnames, font names are validated before they reach generated
CSS/HTML, and uploaded files are checked by extension, size and magic bytes.
